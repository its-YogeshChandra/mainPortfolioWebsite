
  # Replicate Design with Buttons

  This is a Next.js portfolio site migrated from the original Figma-generated Vite React bundle. The original project is available at https://www.figma.com/design/lYwNGqCgX0XM9dXHlaGwyk/Replicate-Design-with-Buttons.

  ## Running the code

  Run `pnpm install` to install the dependencies.

  Run `pnpm run dev` to start the development server.

  Run `pnpm run build` to create a production build.
